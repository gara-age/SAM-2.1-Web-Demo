# SAM 2.1 Vision Console

USB 웹캠 영상에서 객체를 클릭해 분할하고 추적하는 로컬 웹 애플리케이션입니다.
설치 위치: `D:\SAM2TrackingWeb`.

## 실행

1. `D:\SAM2TrackingWeb\start.cmd`를 실행합니다.
2. 브라우저에서 http://127.0.0.1:8000 에 접속합니다.
3. `카메라 시작`을 누릅니다. 카메라가 여러 개면 먼저 `탐색`으로 장치를 선택합니다.
4. `모델 불러오기`를 누릅니다. 생략해도 첫 분할 시 자동으로 로딩됩니다.
5. `객체 추가 · 프레임 고정`을 누르고 영상의 객체 안쪽을 좌클릭합니다.
6. 마스크를 확인하고, 필요하면 좌클릭으로 포함 지점, 우클릭으로 제외 지점을 추가합니다.
7. **`선택 확정 · 추적`을 눌러 영상의 움직임을 추적합니다.** 선택 중 영상이 고정되는 것은 정상 동작입니다.
8. 다른 객체를 추가하려면 `객체 추가`를 다시 누릅니다. 기존 객체의 마스크가 있는 분석 프레임에서 새 객체를 선택합니다.
9. 보정하려면 객체를 선택하고 `보정`을 누릅니다. 지점을 수정한 뒤 다시 확정합니다.

서버 종료는 실행 창에서 Ctrl+C입니다. USB 카메라는 서버 시작만으로 켜지지 않고 웹 화면의 시작 버튼으로 켜집니다.
실행 중인 서버가 있으면 새로 시작하지 말고 기존 주소로 접속하세요. 이 앱은 한 서버에 하나의 공유 작업 상태를 사용하므로 여러 탭의 조작이 같은 작업에 반영됩니다.

## 화면과 측정값

- **분석 프레임:** 마스크와 해당 원본 프레임을 함께 표시합니다. 갱신 속도는 추론 속도에 따릅니다.
- **실시간 원본:** 최신 카메라 영상입니다. 다른 시점의 마스크를 잘못 겹치지 않도록 분석 마스크를 표시하지 않습니다.
- **선택 지점:** 원본 영상의 정수 `(x, y)`, 포함/제외, 선택 당시 프레임 ID입니다. 추적 중 이 지점을 객체의 현재 좌표로 사용하지 않습니다.
- **크기:** 바운딩 박스의 너비·높이(px), 마스크의 실제 픽셀 수(px²), 전체 영상 대비 면적 비율입니다.
- **경계:** `[x_min, y_min, x_max, y_max]` 및 네 꼭짓점, 실제 마스크의 전체 윤곽선 픽셀 좌표입니다. 윤곽선의 `parent` 인덱스로 분리 영역과 구멍의 계층을 확인할 수 있습니다.
- **중심:** 마스크 픽셀 좌표들의 평균인 무게중심입니다. 박스의 중심과 다를 수 있고 오목한 물체에서는 마스크 밖에 위치할 수도 있습니다.
- 원점은 **원본 영상의 왼쪽 위**입니다. x는 오른쪽, y는 아래쪽으로 증가합니다. 화면의 확대/축소를 클릭 좌표 변환에 반영합니다.
- 경계 최댓값은 포함되는 픽셀 인덱스입니다. 너비는 `x_max - x_min + 1`, 높이는 `y_max - y_min + 1`입니다.
- 픽셀 좌표는 2D 영상상의 값입니다. cm·mm 또는 3D 좌표를 뜻하지 않습니다.
- `Pending`: 아직 분할되지 않음. `Active`: 현재 결과에 마스크가 있음. `Lost`: 이전에 선택됐지만 현재 마스크가 비어 있음. 추적 실행/일시정지 여부는 영상 하단에 별도로 표시됩니다.
- 빈 마스크에서는 유효한 크기·중심·경계 좌표를 표시하지 않습니다. 신뢰도 수치를 임의로 만들지 않습니다.
- 마스크·윤곽선·박스·중심점·경로·지점은 각각 표시를 켜고 끌 수 있습니다. 객체별 숨기기와 삭제도 지원합니다.
- 지점 상세 목록의 삭제, 마지막 지점 취소, 현재 지점 초기화를 사용할 수 있습니다. 제외 지점만 남으면 포함 지점을 먼저 추가해야 합니다.
- 경로는 최근 120개의 중심 측정값입니다. 객체를 선택한 후 `이동 경로 초기화`로 지울 수 있습니다.

## 내보내기

상단의 JSON 또는 CSV 버튼을 사용합니다. 마지막으로 게시된 분석 프레임과 그 측정값을 내보냅니다.
JSON에는 선택 지점, 윤곽선 원본 좌표, 경로, 영상 크기, 프레임 ID 및 Unix 시각이 포함됩니다.
CSV에는 객체별 크기·중심·박스·선택 지점 요약이 포함되며, Excel에서 한글이 열리도록 UTF-8 BOM을 사용합니다.
영상·마스크 이미지 자체는 내보내기에 포함하지 않습니다. 필요하면 별도 녹화/이미지 저장 기능으로 확장할 수 있습니다.

## 설치 및 저장 공간

이미 이 PC에는 설치와 빌드가 완료되어 있습니다. 재설치할 때 프로젝트 폴더에서 다음을 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
```

Python 3.10 이상, Node.js, Git, NVIDIA CUDA 호환 드라이버가 필요합니다.
현재 환경은 Python 3.10.11 / Node 24.17 / RTX 2080 SUPER 8GB이며 PyTorch 2.5.1+cu121을 사용합니다.
설치 스크립트는 시스템 Python 환경 대신 프로젝트의 `.venv`를 사용합니다.

| 경로 | 내용 |
|---|---|
| `.venv/` | Python 및 CUDA용 PyTorch 패키지 |
| `.cache/pip/`, `.cache/npm/` | 다운로드 캐시 |
| `.cache/tmp/`, `.cache/frames/` | 설치 및 프레임 처리 임시 파일 |
| `models/sam2.1_hiera_tiny.pt` | 공식 모델 체크포인트, 약 149MiB |
| `vendor/sam2/` | Meta 공식 소스, 고정 커밋 |
| `backend/` | FastAPI, 카메라, 모델 어댑터 및 좌표 계산 |
| `frontend/` | React + TypeScript + Vite, `dist/` 빌드 산출물 |
| `tests/`, `scripts/` | 단위/API 테스트와 실제 모델 통합 검증 |
| `logs/` | 검증 결과 JSON, 환경 기록 |

위의 대용량 파일과 앱의 다운로드·임시 캐시는 D드라이브에 둡니다.
Windows와 브라우저 자체의 시스템 캐시 위치는 변경하지 않습니다.
`setup.ps1`은 현재 검증한 SAM 커밋을 사용합니다. 프로젝트를 다른 위치로 옮긴 경우 가상환경은 새 경로에서 다시 만드세요.

## 검증

프로젝트 폴더에서 실행합니다. 실제 모델 검증은 몇 초 이상 걸리며 GPU를 사용합니다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\smoke_model.py
.\.venv\Scripts\python.exe scripts\smoke_workflow.py
cd frontend
node --test tests/coordinates.test.ts
```

- 단위/API: 사각형·빈 마스크·가장자리·분리 영역·구멍의 좌표 계산, 요청 검증, 프레임 일치, 내보내기, 초기화, 삭제 객체의 재등장 방지.
- `smoke_model.py`: 실제 SAM 2.1 분할, 이동하는 도형의 비디오 추적, 두 객체 및 제외 지점.
- `smoke_workflow.py`: 합성 카메라 입력 + 실제 SAM 2.1 + HTTP/WebSocket으로 3개 객체의 선택·추적·보정·삭제·내보내기 전체 흐름. 모형 마스크를 생성해 대신 반환하지 않습니다.
- `logs/model-smoke.json`, `logs/workflow-smoke.json`에 측정 결과가 저장됩니다.
- 프론트엔드 좌표 변환 테스트는 원본 비율·축소·여백·세로 영상·범위 밖 클릭을 검증합니다. 위 Node 테스트는 현재 설치된 Node 24 환경에서 실행할 수 있습니다.

## 구현 방식과 현재 한계

SAM 2.1의 공식 `init_state`, `add_new_points_or_box`, `add_new_mask`, `propagate_in_video` API를 사용합니다.
이전 분석 프레임과 최대 3개의 새 프레임을 짧은 JPEG 구간으로 구성하고, 이전 마스크를 다음 구간의 시작 조건으로 사용합니다.
구간 간 장기 메모리는 초기화됩니다. 모델 내부의 비공개 텐서나 상태를 스트림용으로 임의 확장하지 않습니다.
프레임 JPEG는 처리가 끝나면 삭제됩니다. 카메라 버퍼는 최대 120프레임, 분석 이력은 12개, 객체 경로는 120개로 제한합니다.
지연된 입력은 버퍼 범위에서 최대 3개 프레임을 균등 샘플링하며 최신 프레임을 포함합니다.

카메라 입력과 추론은 별도 스레드입니다. 단일 모델의 GPU 호출은 직렬화하고 WebSocket의 영상 표시 루프와 분리합니다.
RTX 2080 SUPER에서는 BF16을 사용하지 않고 FP32로 추론합니다. CUDA를 사용할 수 없으면 CPU로 실행하지만 속도가 크게 느려질 수 있습니다.
Windows의 CUDA 확장 빌드는 끄고 추가 연결요소/구멍 채우기 후처리를 비활성화했습니다. 마스크 추론과 OpenCV 기반 좌표 계산은 정상 수행합니다.

속도는 입력 크기·객체 수·GPU 부하에 따라 달라집니다. 입력 30FPS가 곧 SAM 추론 30FPS를 뜻하지 않습니다.
빠른 움직임, 긴 가림, 화면 이탈 후 복귀에 대한 추적 품질과 장시간 안정성은 추가 실제 환경 검증이 필요합니다.
8GB GPU에서 다른 AI 프로그램과 동시에 실행하면 메모리 부족이 발생할 수 있습니다. 오류는 화면에 표시하고 추적을 중지합니다.
신뢰도 수치나 소실 후 자동 재식별 성능은 보장하지 않으며 소실 시 보정/재선택할 수 있습니다.

서버는 기본적으로 `127.0.0.1:8000`에만 바인딩하며 외부 클라우드 추론·업로드·배포를 사용하지 않습니다.
API 문서는 http://127.0.0.1:8000/docs 에서 확인할 수 있습니다.

## 3D 스캔 (v0.2)

카메라 오른쪽의 3D 오브젝트 스캔 패널에서 선택 객체를 여러 각도로 촬영하고 실제 COLMAP 사진측량으로 3D 메시를 만들 수 있습니다.
자세한 촬영 순서, 실패 시 대처 및 저장 경로는 [SCAN_GUIDE.md](SCAN_GUIDE.md)를 참고하세요.

- 새 스캔 → 수동 또는 자동 촬영 → 최소 12장 → 3D 복원.
- 웹에서 드래그 회전·확대·이동, 표면/와이어/점군 전환 및 PLY 내려받기.
- 촬영과 중간 결과는 data/scans에 저장되며 Git에서 제외됩니다.
- 일반 카메라의 다중 시점 복원이므로 카메라 이동과 충분한 사진 겹침이 필요합니다.
- 결과는 상대 크기의 표면 메시입니다. 치수가 보장되는 CAD나 움직이는 대상의 실시간 3D 복원은 아닙니다.
- 새 API 반영 후 화면에 Not Found가 남으면 최신 서버가 실행 중인지 확인하고 브라우저를 새로고침하세요.
- 서버 상태 /api/status의 server_version 값은 0.2.0입니다.

현재 설치·실행 모델은 SAM 2.1입니다. SAM 3.1은 공식 체크포인트 접근 승인 대기 중이며 아직 실행 기능에 통합되지 않았습니다.
